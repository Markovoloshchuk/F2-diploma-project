# 🎮 SM E2ditor (Simple 2D Map Editor)
> **Спеціалізоване кросплатформне середовище візуального проєктування та редагування 2D-рівнів**

---

## 📌 1. Загальна інформація

* **Робоча назва (UA):** SM E2ditor (Simple 2D Map Editor)
* **Working Title (EN):** SM E2ditor (Simple 2D Map Editor)
* **Цільове призначення:** Проєктування, верифікація та експорт двовимірних мап для 2D RPG-ігор.

---

## 💡 2. Актуальність та проблематика

У процесі розробки 2D-ігор незалежними студіями (**інді-розробниками**) ручне формування просторових структур (лейаутів) безпосередньо у вихідному коді призводить до:
* ⏳ Значних часових витрат та зниження продуктивності;
* 👁️ Відсутності візуального контролю на етапі проєктування;
* ⚙️ Високого порогу входу та зайвих накладних витрат при використанні надлишкових універсальних ігрових рушіїв.

### 🎯 Вирішення
**SM E2ditor** надає мінімалістичне, сфокусоване середовище проєктування з детермінованою структурою даних та мінімальними накладними витратами на інтеграцію.

---

## 🏗️ 3. Архітектура та ідея продукту

Спеціалізований кросплатформний десктопний застосунок візуального проєктування та редагування рівнів.

* **Архітектурний тип:** Середовище розробки ігрових мап із модулем керованого рендерингу, багаторівневою історією операцій та мультиформатною серіалізацією.

---

## 🚀 4. Детальний опис функціоналу (Core Features)

| Модуль        | Опис функціоналу |
|---|---|
| **Sprite Slicing & Atlas Management** | Імпорт растрових зображень з автоматизованим або ручним поділом на дискретні тайли за заданими геометричними параметрами та керуванням метаданими. |
| **Canvas Layout Editor** | Інтерактивне середовище візуального позиціювання, трансформації спрайтів і векторних меж (*Boundaries*) із застосуванням структури просторової індексації (**QuadTree**). |
| **Grid Snapping System** | Алгоритмічне прив'язування координат об'єктів до вузлів сітки для забезпечення структурної точності лейауту. |
| **Layering System** | Керування порядком рендерингу (*Z-indexing*) для коректного візуального накладання графічних примітивів. |
| **In-place Tile Patching** | Вбудований растровий мікроредактор на базі **SkiaSharp** для оперативного піксельного редагування тайлів безпосередньо в середовищі з механізмом інвалідації кешу текстурного атласу. |
| **Undo/Redo Stack** | Реалізація паттерну **Command Pattern** для підтримки багаторівневої історії операцій редагування та маніпуляцій з пікселями. |
| **In-engine Playtester** | Середовище верифікації коректності побудови мапи в реальному часі з можливістю налаштування параметрів камери та кінематичних властивостей персонажа. |
| **Multi-format Export** | Генерація структурованих даних у форматах `.json`, `.tmx`, `.csv` та `.lua` із супровідною технічною специфікацією десеріалізації. |

## 🛠️ 5. Технологічний стек та інженерна інфраструктура

### 💻 Програмне забезпечення та мови
* **Мови програмування:** `C#` (`.NET 10+`)
* **UI-фреймворк:** `Avalonia UI` (кросплатформний GUI для Windows та Linux Mint)
* **Графічне ядро:** `SkiaSharp` (апаратно-прискорений 2D-рендеринг, Sprite Slicing, генерація текстурних атласів)

### 📐 Архітектура та формати
* **Паттерни проєктування:** `MVVM`, `Command Pattern`, `Observer`, `Component-based Pattern`
* **Формати даних:** `JSON` (`System.Text.Json`), `TMX` (Tiled Map XML), `CSV`, `Lua`

### 🔧 Інструменти розробки та CI/CD
* **Тестування:** `xUnit` (модульне тестування підсистем серіалізації та геометрії)
* **Автоматизація:** `GitHub Actions` (CI/CD конвеєр для автоматизованої кросплатформної збірки)
* **Середовище розробки:** `Git`, `VS Code`, `Linux Mint` / `Windows`
